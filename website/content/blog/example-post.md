## Why Hugo?

Hugo is a static site generator that offers:

- **Speed**: Pages are generated in milliseconds
- **Flexibility**: Customizable themes and layouts
- **No dependencies**: Binary distribution, no runtime required

## PaperMod Theme

PaperMod is a feature-rich Hugo theme that includes:

- Dark/Light mode support
- Search functionality
- Table of contents
- Social icons integration
- And much more!
